# メモリ目次

> エージェントはセッション開始時、または `.memory/` に関わる作業の前に、このファイルを最初に読む。
> 各行の「参照すべき場面」に該当する時だけ、対象ファイルを読みに行く。全文を毎回読み込む必要はない。

| ファイル | 内容 | 参照すべき場面 |
|----------|------|----------------|
| [rules.md](./rules.md) | メモリの運用規約（書き込み判断・重複矛盾チェック・上限・棚卸し手順） | **メモリへ書き込む前に必ず読む**。`/mem-save` `/mem-prune` 実行時、および自律書き込みを検討する時 |
| [facts.md](./facts.md) | このプロジェクトの設計判断・理由・技術的制約・規約 | 設計判断が必要な時、過去の決定の理由を確認したい時 |
| [progress.md](./progress.md) | 現在の作業状態・次に取るべきアクション | セッション開始時、作業を再開・引き継ぐ時 |
| [sessions.md](./sessions.md) | 過去セッションで何をしてどうなったかの経緯ログ | 「前回何をしたか」を確認したい時、経緯を遡りたい時 |
| [pitfalls.md](./pitfalls.md) | 過去のハマりどころ・やってはいけないこと | 実装・デバッグに着手する前。特に一度失敗した領域に触れる時 |

## 自律書き込み

- `memory_auto_write: on`（このファイル冒頭のfrontmatter）の間、エージェントは記憶に値する情報を自律的に書き込んでよい
- `off` にすると自律書き込みを停止し、`/mem-save` 実行時のみ書き込む
- 自律書き込みを行った場合、**セッションの最後に「何を .memory/ のどのファイルに書き込んだか」を必ず報告する**（ブラックボックス化防止）
- 書き込み前に必ず [rules.md](./rules.md) の判断基準・重複チェック手順に従うこと
