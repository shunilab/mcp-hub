# メモリ運用規約

このファイルは `.memory/` を読み書きするすべてのエージェントが従う規約。エージェント固有機能に依存しない自然言語の指示のみで構成する。

---

## エントリの基本フォーマット

`facts.md` / `pitfalls.md` のような蓄積型ファイルでは、各エントリを次の形式で書く。

```markdown
### エントリのタイトル
作成: YYYY-MM-DD / 確認: YYYY-MM-DD

本文（理由・背景・適用条件を含める）
```

- 「作成」はエントリを新規に書いた日。以後変更しない
- 「確認」はエントリの内容が**現在も有効であると実際に検証した日**。棚卸し（`/mem-prune`）のたびに全エントリを機械的に更新するのは禁止 — 検証していないエントリの確認日を更新すると、鮮度メタデータが意味を持たなくなる
- `sessions.md` は蓄積型だが追記専用ログのため、上記フォーマットではなく「## YYYY-MM-DD」見出し＋箇条書きで良い（詳細は sessions.md 冒頭のコメントを参照）

---

## 1. 何を書き込むか（書き込みノイズ対策）

書き込む前に、次の問いに一つでも「はい」と答えられるか確認する。答えられなければ書き込まない。

- これは**このコードやgit履歴から再現できない**情報か（設計判断の理由、なぜその実装を選んだか等）
- これは**将来のセッションで同じ調査・同じ失敗を繰り返さないために**必要な情報か
- これは**今のタスクの一時的な詳細ではなく**、プロジェクトの前提として残る情報か

該当しないものの例: 一時的な作業メモ、既にコードやコミットメッセージで自明な内容、今回限りのタスクの手順。

## 2. 重複・矛盾チェック（書き込み前に必ず行う）

新しいエントリを書く前に、書き込み先ファイルの既存エントリを確認し、

- 同じ内容のエントリが既にあれば、新規追加ではなく既存エントリの更新（確認日の更新を含む）にする
- 既存エントリと矛盾する内容であれば、古い方を削除するか「上書き: なぜ判断が変わったか」を明記して更新する。矛盾したまま両方残さない

## 3. 肥大化対策（上限の目安）

- `facts.md` / `pitfalls.md`: 各ファイル30エントリを目安の上限とする。近づいたら関連エントリを統合・要約する
- `sessions.md`: 直近10セッション分を目安に保持する。それより古いものは `/mem-prune` 時に要約して `facts.md`（恒久的な決定事項なら）に昇格するか、単に削除する
- `progress.md`: 「現在の状態」のみを保持するファイルなので、完了した項目は都度削除し、蓄積させない

## 4. 陳腐化対策（棚卸し）

- `/mem-prune` を実行するタイミングで、各エントリの「確認」日と現在の状態を照合する
- 実際にコードやプロジェクト状態を見て有効性を検証したエントリだけ確認日を更新する
- 無効化したエントリは削除するか、「廃止: 理由」を追記してから削除する（削除前の記録は不要、rules.mdのこの規約自体がプロセスの記録）

## 5. 参照漏れ対策

- セッション開始時に `index.md` を必ず読む（Claude Code環境では SessionStart hook が自動で行う。hooksがない環境では `/mem-load` を最初に実行する）
- `index.md` の「参照すべき場面」に該当したら、都度そのファイルを読みに行く

## 自律書き込みとその報告

- `index.md` の frontmatter `memory_auto_write` が `on` の間は、上記1〜2の基準を満たす情報を自律的に書き込んでよい
- 自律書き込みを行った場合、セッションの最後に「`.memory/○○.md` に △△を書き込んだ」という報告を必ず行う。書き込んでいない場合は報告不要
- `memory_auto_write: off` の場合は `/mem-save` 実行時のみ書き込む

## 手動コマンド一覧

- `/mem-save` — 今回のセッションの内容から、上記1〜2の基準を満たすものを抽出し、適切なファイルに書き込む
- `/mem-prune` — 上記3〜4の棚卸しを実行する
- `/mem-load` — `index.md` を読み、現在のタスクに関連するファイルを判断して読み込む（hooksがない環境での参照漏れ補完）

Claude Code以外の環境（hooksのないエージェント）では、これらはスラッシュコマンドではなく、ユーザーが上記のプロンプト文をそのまま入力することで実行する。
