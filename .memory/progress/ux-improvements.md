# UX改善バックログ

作成: 2026-07-17

ユーザーとの議論で採用が決まったUX改善案。着手時に個別タスク化する。

## 採用済みの案

1. **同期前の差分プレビュー** — ドラッグ&ドロップ実行前に「どのクライアントのconfigに何を追加/削除するか」を確認ダイアログで表示し、OKで初めて書き込む。設定でオフにできるようにする
2. **外部変更の検出** — クライアント設定は他ツールや手編集でも変わるため、起動時・フォーカス復帰時に再読込し、ハブと食い違うサーバーにバッジを表示する
3. **undoの発見性** — 同期直後に「◯◯を移動しました — 元に戻す」トーストを数秒表示。Cmd+Zの存在を知らなくても救済手段に気づける
4. **エラーの翻訳** — CLIのstderrをそのまま出さず、よくある失敗（Node.js未検出、config書き込み権限なし等）を人間の言葉＋次の一手（インストール手順リンク、該当パス表示）に変換して表示する
5. **初回起動の空状態** — 空カンバンのままにせず、「既存クライアントの設定からサーバーを取り込む」「Discoverから探す」の2ボタンを空状態に配置し、最初の1分で価値に到達できる導線を作る
6. **操作中の応答性** — 全操作がNodeプロセス起動を伴い無反応時間が出るため、ドロップ時はカードを楽観的に移動表示し失敗時に戻す。最低限、操作対象カードにスピナーを表示して「押したのに何も起きない」を潰す
7. **サーバーの検索・フィルタ** — サーバーが増えると列を目で追うのが辛いため、名前でのインクリメンタル絞り込みを付ける
8. **環境変数・APIキーのマスク表示** — カード詳細で `env` の値を伏せ字にし、編集時だけ表示。画面共有時の事故防止
9. **サーバーの一時無効化トグル** — 削除せずオフにできるようにし、試行錯誤中に消して作り直す手間をなくす
10. **設定ファイルへの直行導線** — 各列ヘッダーから「configをエディタで開く」「パスをコピー」。トラブル時の脱出口
11. **ショートカット一覧** — Cmd+Z/Cmd+Rは現状知る手段がないため、`?` キーでヘルプオーバーレイを表示する
12. **Discoverのインストール後導線** — インストールして終わりでなく、「どのクライアントに配るか」まで同じフローで完結させる

## 優先順位（2026-07-17 決定）

1. **第1弾: 6 + 3**（楽観的UI＋undoトースト）— 実装が軽く全操作の体感に効く。「即反応して、間違えても戻せる」を成立させる
2. **第2弾: 2 → 1**（外部変更検出→差分プレビュー）— 表示の信頼性を固める
3. **第3弾: 5 + 4**（空状態＋エラー翻訳）— 新規ユーザー獲得を狙う段階で
4. **随時: 7〜12** — 小粒なので合間に
